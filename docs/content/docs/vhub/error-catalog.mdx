# Code Catalog (F5)

Every failure and verdict in the system carries one code from a **closed catalog of 77 codes**. The catalog lives in `internal/core/codes/catalog.tsv`; a test checks that the Go constants and the catalog match.

| Column | Meaning |
|:---|:---|
| **Emitter** | `C-HUB` (`alexandria-server`) or `C-CLI` (`alexandria-client`). |
| **Channel** | `problem`: `application/problem+json` response. `startup`: non-zero exit at start. `sync`: `vhub.sync` event. `classification`: result of a gate. `event`: informational event. |
| **Severity** | `error`, `warning` or `info`. |

Problem documents follow RFC 9457 with the extensions `code`, `severity` and, for validation, `findings[]`; their `type` is `https://w3id.org/alexandria-vhub/problems#<CODE>`. Hub problems are JSON-LD and carry `@context`.

<Callout type="info">
The PoC compiler and evaluator add implementation codes outside the catalog (`POC_N1`–`POC_N5`, `POC_EVAL_UNSUPPORTED_ROLE`). One catalog code, `VERDICT_SHACL_WARNING`, is unreachable in this PoC because the evaluator does not execute SHACL (`DP-7`).
</Callout>
