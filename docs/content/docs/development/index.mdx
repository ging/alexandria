# API & Development

Alexandria exposes cleanly separated HTTP surfaces across its components:
1. **Identity & Wallet Gateway (`cmd/alexandria`):** Mounted under `/api/v1` (`auth` and `wallet`), guarded by Zitadel OIDC session cookies or Bearer tokens, plus interactive **Swagger UI** at `/docs` (`/openapi.json`, `/openapi.yaml`) and root W3C DID Document resolution at `/.well-known/did.json`.
2. **Vocabulary Hub Server (`cmd/alexandria-server`):** Exposes the `/v1/*` Governance API (protected by role-based Bearer authentication), the public immutable `/pub/*` artifact distribution API, and `/.well-known/did.json`.
3. **Edge Validation Sidecar (`cmd/alexandria-client`):** Exposes L7 DSP reverse/forward proxy listeners (`dsp-ingress`, `dsp-egress`, `mgmt-ingress`) and an isolated local Admin & Prometheus telemetry API (`admin` port: `/status`, `/versions`, `/agreements`, `/audit`, `/metrics`).
