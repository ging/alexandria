# API & Development

Alexandria exposes three HTTP surfaces:

1. **`/v1` on `alexandria-server`** — the management API. JSON-LD, OAuth 2.0 bearer tokens, problem documents on error.
2. **`/pub` on `alexandria-server`** — public, immutable publication.
3. **The admin listener of `alexandria-client`** — status, rules, agreements, audit, health and metrics. The traffic listeners are transparent proxies and expose no API of their own.
