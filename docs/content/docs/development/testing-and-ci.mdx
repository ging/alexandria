# Testing, Archtest & CI/CD

Alexandria uses strict, multi-layered quality gates across unit tests, architectural AST tests, normative conformance tests, and live container integration suites.

---

## 1. Vocabulary Hub Test Suite (`Makefile`)

All `vhub` (`alexandria-server`, `alexandria-client`, `alexandriac`, `internal/core`, `internal/dsl`) tests run without external containers:

```bash
# 1. Build alexandria-server, alexandria-client, and fake-connector into ./bin:
make build

# 2. Run all unit, contract, and hexagonal architecture tests:
make test

# 3. Run the full conformance suite (T-DOC-*, T-SYS-*, 63 N-<CODE> tests, and TestE2E_F6):
make conformance

# 4. Run only the real-binary Scenario F6 end-to-end test:
make e2e

# 5. Run the interactive F6 demo and print the 19-row verdict table:
make demo

# 6. Verify 100% requirement & catalog coverage and regenerate TRACEABILITY.md:
make trace
```

### Architectural Gate (`internal/archtest`)
Included automatically in `make test` and `task test`, `internal/archtest/arch_test.go` verifies:
- **Hexagonal Layer Isolation:** `domain` packages never import `app` or `adapters`; `app` packages never import `adapters`; `internal/server` and `internal/client` never import each other; `internal/dsl` never imports `server`, `client`, `clock`, or `testkit`.
- **Dependency Allowlist (`DP-1`):** Ensures no unauthorized third-party packages enter the `vhub` dependency tree.
- **Deterministic Clock Enforcement (`DP-9`):** Scans the Go AST of all `vhub` production packages to guarantee `time.Now()` is never called outside `internal/clock`.

## 2. Identity & Wallet Test Suite (`Taskfile.yaml`)

### Unit Tests & Coverage
Executes unit tests across the entire repository with race detection and `-tags=jwx_es256k`, generating `coverage.out`:

```bash
task test
task cover
```

### Live Wallet Integration Tests (`//go:build integration`)
Integration tests verify `internal/ssi-auth/fafnir` and `internal/ssi-auth/identityhub` against live Docker containers (and skip gracefully via `t.Skip` if the target container is unreachable):

```bash
# Run all integration tests:
task test:integration

# Test Fafnir wallet adapter specifically:
task test:integration:fafnir

# Test Eclipse EDC IdentityHub adapter specifically:
task test:integration:identityhub

# Run both unit and integration suites:
task test:all
```

*(When running `go test` manually for integration suites, always pass `-tags="integration,jwx_es256k"`.)*

## 3. Code Quality & Linters

Before opening a pull request, run the full verification pipeline:

```bash
task check
```

`task check` executes:
1. **`task fmt`:** Formats all Go files with `gofumpt`.
2. **`task lint`:** Runs static analysis with `golangci-lint`.
3. **`task test`:** Runs the unit test suite with the race detector.

Additional verification commands:
```bash
# Verify go.mod / go.sum are clean:
task tidy

# Scan dependencies for known CVEs with govulncheck:
task vuln
```

---

## 4. Continuous Integration (GitHub Actions)

1. **`ci.yaml`:**
   - Runs on every push to `main` and all Pull Requests.
   - Verifies `go mod tidy` cleanliness, `gofumpt` formatting, `go vet`, `golangci-lint`, race-enabled unit tests, `govulncheck`, and binary compilation.
2. **`deploy-docs.yaml`:**
   - Builds the static Next.js / Fumadocs portal (`task docs:build`) and deploys it to GitHub Pages at `https://ging.github.io/alexandria/`.
