# Configuration Reference

This guide documents all configuration files used across the Alexandria repository:
1. **`config/server.json` & `config/tokens.json`:** Configuration for `alexandria-server` (`C-HUB`).
2. **`config/config.json` & `config/routes.default.json`:** Configuration for `alexandria-client` (`C-CLI`), validated against Appendix A.3 (`conformance/schemas/config.schema.json`).
3. **`config/config.yaml` & `config/config-ih.yaml`:** Configuration for `cmd/alexandria` (Identity, Zitadel OIDC, and Fafnir/IdentityHub wallets).

---

## 1. `alexandria-server` Configuration (`config/server.json`)

`alexandria-server` validates its configuration file against `config/server.schema.json` on startup (`DP-12`). Pass `-config <path>` to specify a custom path.

```json
{
  "listen": "127.0.0.1:8080",
  "public_base_url": "http://localhost:8080",
  "did": "did:web:localhost%3A8080",
  "sqlite_path": "../var/hub/hub.db",
  "blob_dir": "../var/hub/blobs",
  "signing_key_path": "../var/hub/hub.key",
  "tokens_path": "tokens.json",
  "compiler": "dsl",
  "vendor_dir": "vendor"
}
```

### Field Reference (`server.schema.json`)

| Field | Type | Required | Description |
|:---|:---|:---:|:---|
| `listen` | `string` (`host:port`) | Yes | TCP address where `alexandria-server` binds (`/v1`, `/pub`, `/.well-known/did.json`). |
| `public_base_url` | `string` (`http(s)://...`) | Yes | External base URL used when constructing public artifact links. |
| `did` | `string` (`did:web:...`) | Yes | The Hub's W3C `did:web` identifier (e.g., `did:web:localhost%3A8080`). |
| `sqlite_path` | `string` | Yes | Path to the SQLite database file (created automatically with immutability triggers). |
| `blob_dir` | `string` | Yes | Content-addressed directory (`<blob_dir>/sha256/<hex>`) for compiled package blobs. |
| `signing_key_path` | `string` | Yes | Path to the Ed25519 PKCS#8 PEM signing key (auto-generated on first boot if absent). |
| `tokens_path` | `string` | Yes | Path to the static Bearer token map (`config/tokens.json`). |
| `compiler` | `"poc"` \| `"dsl"` | No | Draft compiler mode: `"dsl"` compiles `eunomia.profiles/v1` YAML bundles; `"poc"` compiles simplified JSON drafts (default: `"poc"`). |
| `vendor_dir` | `string` | No | Directory holding local copies of vendored profiles (`<slot>/<version>/vendor.json`) for `compiler: "dsl"`. |
| `clock_file` | `string` | No | Path to an RFC 3339 timestamp file for deterministic testing (`DP-9`; can also be set via `-clock-file`). |
| `lifecycle` | `object` | No | Default lifecycle durations (`freshness.ttl`, `freshness.max_staleness`, `grace_window`, `sync_interval`, `clock_skew`, `lease_margin`, `propagation_window`, `max_concurrent_versions`, `degraded`). |

### Static Authentication (`config/tokens.json`)

Maps Bearer tokens to a `principal` name and an array of governance `roles` (`editor`, `reviewer`, `authority` / `releaser`, `member`, `operator`):

```json
{
  "editor-token":   {"principal": "steward",     "roles": ["editor"]},
  "releaser-token": {"principal": "releaser",    "roles": ["releaser"]},
  "member-token":   {"principal": "alexandria-client", "roles": ["member"]}
}
```

## 2. `alexandria-client` Configuration (`config/config.json`)

On startup, `alexandria-client` validates `config/config.json` against five strict invariants (`CFG-1` to `CFG-5`, `REQ-CLI-001`) and exits with code `2` if any check fails:
- **`CFG-1` (`CONFIG_SCHEMA`):** Conforms to the normative Appendix A.3 JSON Schema (`conformance/schemas/config.schema.json`).
- **`CFG-2` (`CONFIG_ROUTE_OVERLAP`):** No two routes on the same listener have overlapping HTTP method and path patterns (e.g., `:a` vs `:b` in the same segment).
- **`CFG-3` (`CONFIG_GATE_MESSAGE_MISMATCH`):** Gates assigned to a route are compatible with its DSP `message` type (e.g., `agreement_admission` is only valid on `TransferRequestMessage`).
- **`CFG-4` (`CONFIG_CREDENTIALS_UNREADABLE`):** The token file referenced by `trust.credentials` exists and is readable.
- **`CFG-5` (`CONFIG_UPSTREAM_MISSING`):** Every listener used by a route has its corresponding upstream URL configured (`upstreams.dsp` or `upstreams.management`).

### Example `config/config.json`

```json
{
  "space": "https://example.com/spaces/demo",
  "trust": {
    "hub_did": "did:web:localhost%3A8080",
    "hub": "https://localhost:8080",
    "credentials": "file:config/credentials.json",
    "did_ttl": "PT1H"
  },
  "upstreams": {
    "dsp": "http://127.0.0.1:8282/protocol"
  },
  "listeners": {
    "dsp-ingress": { "bind": "127.0.0.1:8443" },
    "dsp-egress":  { "bind": "127.0.0.1:3128" },
    "admin":       { "bind": "127.0.0.1:9900" }
  },
  "routes": [
    {
      "listener": "dsp-ingress",
      "match": { "method": "POST", "path": "/negotiations/request" },
      "message": "ContractRequestMessage",
      "gates": ["dsp_message", "policy_intake"],
      "mode": "enforce",
      "body": { "select": "$.offer.permission[0]" }
    },
    {
      "listener": "dsp-ingress",
      "match": { "method": "POST", "path": "/transfers/request" },
      "message": "TransferRequestMessage",
      "gates": ["dsp_message", "agreement_admission"],
      "mode": "enforce"
    }
  ],
  "default_action": "forward",
  "unknown_agreement": "forward",
  "events": {
    "sink": "file:var/client/events.jsonl"
  }
}
```

<Callout type="info">
**Default DSP Routes (`DP-10`):** If `routes` is omitted or empty, `alexandria-client` automatically loads the 16 standard DSP 2025-1 routes (`config/routes.default.json`) in `observe` mode.
</Callout>

## 3. Identity & Auth Node Configuration (`config/config.yaml`)

`cmd/alexandria` implements the **One Configuration Document** pattern ([ADR 0002](../adr/0002-one-configuration-document)), reading `config/config.yaml` (or `config/config-ih.yaml` for IdentityHub) and allowing any key to be overridden via `ALEXANDRIA_<SECTION>_<KEY>` environment variables.

### `common_config`
```yaml
common_config:
  hosts:
    http:
      protocol: "https"
      url: "alexandria.127.0.0.1.nip.io"
      port: "8443"            # External Caddy TLS port
      internal_port: "1234"   # Internal cleartext HTTP port
  db:
    db_type: Postgres
    url: "127.0.0.1"
    port: "1500"
    user: "alexandria"
    password: "alexandria"
    name: "alexandria"
  api:
    version: "v1"
    openapi_path: "./static/specs/openapi/merged_openapi.json"
  connection:
    is_local: true
    is_prod: false
    is_vault_real: false
    has_tls_proxy: true
```

### `wallet_config`
```yaml
wallet_config:
  wallet: Fafnir              # Fafnir | IdentityHub
  api:
    http:
      protocol: "http"
      url: "127.0.0.1"
      port: "7003"            # 7003 for Fafnir, 8181 for IdentityHub
  startup_link_timeout: "10s"
```

### `auth_config` & `observability`
```yaml
auth_config:
  enabled: true
  issuer: "https://auth.127.0.0.1.nip.io:8443"
  client_id: ""               # Injected via .env by task auth:bootstrap
  client_secret: ""           # Injected via .env by task auth:bootstrap
  redirect_url: "https://alexandria.127.0.0.1.nip.io:8443/api/v1/auth/callback"
  app_url: "https://alexandria.127.0.0.1.nip.io:8443/"
  introspect: "fallback"      # never | fallback | always
  session:
    name: "alexandria_session"
    secure: true
    same_site: "lax"
    ttl: "12h"

observability:
  log_level: "info"
  log_format: "auto"
  metrics: true
  pprof: false
  port: "2112"
```

### Common Environment Variable Overrides
```bash
# Switch to Eclipse EDC IdentityHub on port 8181:
ALEXANDRIA_WALLET_CONFIG_WALLET=IdentityHub \
ALEXANDRIA_WALLET_CONFIG_API_HTTP_PORT=8181 \
task dev

# Disable OIDC authentication for automated testing:
ALEXANDRIA_AUTH_CONFIG_ENABLED=false task test
```
