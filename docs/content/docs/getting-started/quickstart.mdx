# Quickstart

Welcome! Whether you prefer exploring visually in the **Alexandria Console** or scripting everything from the terminal, you can have a complete Vocabulary Hub and edge validation sidecar running locally in about two minutes.

Let's build the binaries first, then either launch the one-command demo or start the 4-process lab yourself.

---

## Option A — One-Command Automated Replay

From the repository root:

```bash
make demo
```

This builds all five Go binaries into `bin/`, launches `fake-idp`, `alexandria-server`, `fake-connector`, and `alexandria-client` on free local ports with a simulated clock, and replays the full normative **Scenario F6** lifecycle (`1.0.0 initial` -> `2.0.0 breaking` -> grace window -> cutoff & agreement revocation) printing every verdict along the way.

---

## Option B — Interactive Lab (Console + Terminal)

To click through the visual **Alexandria Console** (recommended while following the [Tutorials](../tutorials)) or drive the HTTP APIs yourself:

<Steps>

### Build binaries with the embedded Console

If you want `alexandria-server` and `alexandria-client` to serve the browser Console directly under `/ui/`, use `build-gui` (requires Node.js + pnpm):

```bash
make build-gui
```

Or build only the Go binaries (`make build`) and run the standalone Console dev server in `gui/` (`make gui-dev` on `http://localhost:5273`) so both **Server** and **Client** workspaces live side by side in one tab.

### Start the laboratory processes

Open four terminals (or background them cleanly):

```bash
# 1. Laboratory OIDC identity provider (http://127.0.0.1:9400)
./bin/fake-idp serve

# 2. Vocabulary Hub server (https://127.0.0.1:8443)
./bin/alexandria-server -config config/server.yaml

# 3. Upstream DSP connector (http://127.0.0.1:8282)
./bin/fake-connector -listen 127.0.0.1:8282
```

Notice on first boot `alexandria-server` generates a laboratory signing key, derives its **Hub DID** (`did:key:...`), and prints a self-signed certificate under `var/tls/hub.crt`. Copy that **Hub DID** (you can grab it with one click from the Console sidebar or `/v1/namespaces/{ns}/versions`), put it in `config/client.yaml` under `did_config.hub_did`, and start the edge sidecar:

```bash
# 4. Edge validation proxy (ingress :9080, egress :9081, admin :9090)
./bin/alexandria-client -config config/client.yaml
```

### Open the Console and follow the GreenCity Mobility story

- If using the embedded Console:
  - Hub workspace: `https://127.0.0.1:8443/ui/` (accept the local lab TLS warning)
  - Client workspace: `http://127.0.0.1:9090/ui/`
- If using `make gui-dev`: open `http://localhost:5273/` to switch seamlessly between **Server** and **Client** with `g w`.

<Callout type="info">
To sign in quickly during local labs, open the **Identity** menu at the top right, choose **Sign in with OIDC**, and use the one-click `fake-idp` presets (`ana · admin` or `sergio · steward`).
</Callout>

</Steps>
