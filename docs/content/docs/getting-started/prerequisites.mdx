# Prerequisites

---

## Tooling

| Tool | Version | Needed for |
|:---|:---:|:---|
| **Go** | as pinned in `go.mod` | Building the binaries and running every test suite. SQLite is embedded (`modernc.org/sqlite`, no `cgo`). |
| **GNU Make** or **[Task](https://taskfile.dev)** | any recent | The `Makefile` and `Taskfile.yaml` expose the same targets. |
| **Node.js and pnpm** | 20+ / 10+ | Optional. The console (`gui/`) and this documentation site (`docs/`). |
| **Python 3** | 3.10+ | Optional. The Jupyter tutorials in `tutorial/`. |

<Callout type="info">
`make build test conformance e2e trace` needs only Go. No containers, databases or external services are required: the demo and the end-to-end test start the real binaries on free local ports.
</Callout>

---

## Default Ports

These are the values of the sample configurations in `config/` and `deploy/`.

| Port | Process | Listener | Purpose |
|:---:|:---|:---|:---|
| **8443** | `alexandria-server` | `listen` (HTTPS) | `/v1` management API, `/pub` publication and, when embedded, the console at `/ui/`. |
| **9400** | `fake-idp` | — | OIDC discovery, JWKS, `/authorize`, `/token`. |
| **8282** | `fake-connector` | — | Upstream DSP connector of the client. |
| **9080** | `alexandria-client` | `dsp-ingress` | Reverse proxy for inbound DSP messages. |
| **9081** | `alexandria-client` | `dsp-egress` | Forward proxy for outbound DSP messages. |
| **9090** | `alexandria-client` | `admin` | Admin API, metrics and, when embedded, the console at `/ui/`. |
| **5273** | Vite | — | Console development server (`make gui-dev`). |
| **3000** | Next.js | — | Documentation development server (`make docs-dev`). |

<Callout type="warn">
Port `9090` is commonly taken by other tools. If the client admin listener fails to bind, change `listeners.admin.bind` in the client configuration.
</Callout>

The hub generates its Ed25519 signing key and a self-signed laboratory TLS certificate on first start when the configured files are absent. The client must be told to trust that certificate (`connection.tls.ca` in the section layout, or the `-hub-ca` flag).
