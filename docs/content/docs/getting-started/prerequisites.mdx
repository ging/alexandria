# Prerequisites

Before developing or running Alexandria locally, ensure your workstation meets the following runtime and tooling dependencies.

---

## Required Tooling

| Dependency | Minimum Version | Purpose |
|:---|:---:|:---|
| **Go** | `1.26+` | Compiles the node application and runs tests. |
| **Docker & Compose** | `24+` / v2 | Runs PostgreSQL, Zitadel, Caddy proxy, and wallets. |
| **[Task](https://taskfile.dev)** | `3+` | Project task runner that manages environments, builds, and lifecycle commands. |
| **OpenSSL** | `3+` | Generates local Certificate Authority (CA) and certificates (preinstalled on macOS/Linux). |

<Callout type="warn">
`task` is mandatory: commands defined in `Taskfile.yaml` automate certificate trust, load `.env` secrets, and coordinate multi-container dependencies.
</Callout>

---

## Local Network & DNS (`nip.io`)

Alexandria terminates TLS even in local development using **Caddy** (see [ADR 0005](../adr/0005-tls-terminated-by-a-proxy-in-development-too)). All services bind locally using subdomains routed through `127.0.0.1.nip.io`:

- **Node Portal & API:** `https://alexandria.127.0.0.1.nip.io:8443`
- **Zitadel IAM:** `https://auth.127.0.0.1.nip.io:8443`
- **Wallet Service (Fafnir / IdentityHub):** Bound to `http://127.0.0.1:7003`

`nip.io` maps any wildcard IP prefix directly back to loopback `127.0.0.1` without requiring modifications to `/etc/hosts`.

---

## Local Port Allocation

Ensure the following TCP ports are available on your machine:

| Port | Service | Bound To | Protocol | Notes |
|:---:|:---|:---:|:---:|:---|
| **`8443`** | Caddy Reverse Proxy | Host | HTTPS | Single TLS entrypoint for external callers. |
| **`1234`** | Alexandria Node Core | Internal | HTTP | Listens in the clear behind Caddy. |
| **`1500`** | PostgreSQL 17 | Host | TCP | Relational persistence for node state. |
| **`1600`** | Zitadel Console & Direct API | Host | HTTP/gRPC | Direct container access for bootstrap scripts. |
| **`7003`** | Wallet Service (Fafnir) | Host | HTTP | Provides cryptographic signing and DID storage. |
| **`2112`** | Prometheus Metrics / pprof | Internal | HTTP | Observability endpoints (`/metrics`). |
