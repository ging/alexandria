# Prerequisites

Before running or developing with Alexandria, ensure your workstation meets the requirements for the workflow you want to run.

---

## Required Tooling

### For `alexandria-server`, `alexandria-client`, and `alexandriac` (Zero External Dependencies)
The Vocabulary Hub reference implementation (`vhub`) is self-contained in pure Go (using embedded `modernc.org/sqlite` without `cgo`):

| Dependency | Minimum Version | Purpose |
|:---|:---:|:---|
| **Go** | `1.22+` (`1.26+` recommended) | Compiles `alexandria-server`, `alexandria-client`, `alexandriac`, and runs conformance tests. |
| **GNU Make** | `3.81+` | Runs `make build`, `make test`, `make conformance`, `make demo`, and `make trace`. |

### For the Full `alexandria` Identity Stack (Docker + Zitadel + Wallets)
To run the full multi-container identity environment (`cmd/alexandria` with PostgreSQL, Caddy TLS, Zitadel OIDC, Fafnir, or Eclipse EDC IdentityHub):

| Dependency | Minimum Version | Purpose |
|:---|:---:|:---|
| **Docker & Compose** | `24+` / v2 | Manages PostgreSQL, Zitadel IAM, Caddy reverse proxy, Fafnir, IdentityHub, and Vault. |
| **[Task](https://taskfile.dev)** | `3+` | Orchestrates certificate generation, container bootstrap, `.env` secrets, and hot-reload. |
| **OpenSSL** | `3+` | Generates the local root Certificate Authority (CA) in `/.certs/`. |
| **Node.js & pnpm** | `20+` / `10+` | Optional: builds and previews this Fumadocs documentation portal (`task docs:dev`). |

<Callout type="info">
You can build and test the entire `vhub` suite (`alexandria-server`, `alexandria-client`, `alexandriac`, and the F6 end-to-end scenario) **without Docker or sudo** using `make build test conformance demo`.
</Callout>

## Port Allocation Map

### 1. Vocabulary Hub (`alexandria-server` & `alexandria-client`) Default Ports
When running `alexandria-server` (`config/server.json`) and `alexandria-client` (`config/config.json`) with default configurations:

| Port | Component | Listener | Protocol | Description |
|:---:|:---|:---|:---:|:---|
| **`8080`** | `alexandria-server` | `listen` | HTTP | Serves `/v1/*` governance API, `/pub/*` artifacts, and `/.well-known/did.json`. |
| **`8443`** | `alexandria-client` | `dsp-ingress` | HTTP | L7 reverse proxy intercepting inbound DSP messages toward the local Connector. |
| **`3128`** | `alexandria-client` | `dsp-egress` | HTTP | L7 forward proxy intercepting outbound DSP messages from the local Connector. |
| **`9900`** | `alexandria-client` | `admin` | HTTP | Local admin & observability API (`/status`, `/versions`, `/agreements`, `/metrics`). |
| **`8282`** | Connector / `fake-connector` | `upstreams.dsp` | HTTP | Upstream dataspace connector receiving validated DSP traffic. |

*(Note: `make demo` and `make e2e` automatically allocate ephemeral free ports on `127.0.0.1` so they never conflict with running services.)*

### 2. Identity & SSI Gateway (`cmd/alexandria`) Ports
When running the full Docker stack via `task dev:auto`:

| Port | Service | Bound To | Protocol | Notes |
|:---:|:---|:---:|:---:|:---|
| **`8443`** | Caddy Reverse Proxy | Host | HTTPS | Primary TLS entrypoint (`https://alexandria.127.0.0.1.nip.io:8443`). |
| **`1234`** | Alexandria Node Core | Internal | HTTP | Listens in the clear behind the Caddy TLS reverse proxy. |
| **`1500`** | PostgreSQL 17 | Host | TCP | Relational persistence for node state and credentials. |
| **`1600`** | Zitadel Console & API | Host | HTTP/gRPC | Direct container access for bootstrap automation and admin console. |
| **`7003`** | Fafnir Wallet | Host | HTTP | Default wallet backend providing key custody and DID signing. |
| **`8181` / `8182`** | Eclipse EDC IdentityHub | Host | HTTP | Enterprise wallet backend (`task identityhub:up`). |
| **`8200`** | HashiCorp Vault | Host | HTTP | Optional backend for Fafnir key storage (`task vault:up`). |
| **`2112`** | Prometheus Metrics / pprof | Internal | HTTP | Observability endpoints (`/metrics`, `/debug/pprof`). |
| **`3000`** | Documentation Server | Host | HTTP | Local Fumadocs preview server (`task docs:dev`). |
