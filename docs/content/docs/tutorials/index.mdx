# Tutorials

The tutorials build on each other. Tutorials 2 to 5 assume the laboratory of the [quickstart](../getting-started/quickstart) is running: `fake-idp`, `fake-connector`, `alexandria-server` and `alexandria-client`.

```text
 1. Profile language ──► 2. Hub governance ──► 3. Edge proxy
                                                    │
                    5. Failure cases ◄── 4. Breaking changes and F6
```
