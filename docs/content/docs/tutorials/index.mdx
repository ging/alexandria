# Incremental Tutorials

This tutorial track takes you step by step from writing your first vocabulary profile in YAML to governing multi-version lifecycles on `alexandria-server`, enforcing Dataspace Protocol (DSP) policies at the edge with `alexandria-client`, and managing cryptographic identities with Fafnir and Eclipse EDC IdentityHub.

<Callout type="info">
**Designed for Hands-On Learning:** Every tutorial builds on the concepts of the previous one and uses real commands you can copy and paste directly in your terminal. Tutorials 1 through 4 require only Go (`make build`)—no Docker containers needed!
</Callout>

---

## Learning Path Progression

```
  [Tutorial 1]                  [Tutorial 2]                  [Tutorial 3]
  eunomia.profiles/v1 YAML  ──► alexandria-server Governance    ──► alexandria-client Sidecar Proxy
  (alexandriac validate/compile)      (/v1/drafts -> /pub/)         (S1-S13 sync, DSP gates)
                                                                       │
                                                                       ▼
                                [Tutorial 5]                  [Tutorial 4]
                                Wallets & IdentityHub     ◄── Breaking Changes & F6
                                (DIDs, Keys, VCs, DCP)        (Grace windows, Revocation)
```
