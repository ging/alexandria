# 3. Edge Validation Sidecar (`alexandria-client`)

With `mobility` **`1.0.0`** live on the hub, let's bring GreenCity's edge validation sidecar (**`alexandria-client`**) online. The sidecar verifies cryptographic hub signatures once during sync, compiles an in-memory gate bundle, and validates every inbound/outbound DSP request in milliseconds **with zero network calls on the request path**.

### Configure trust and start the client

Copy the **Hub DID** you grabbed in Tutorial 2 into your client config (`trust.namespace: "mobility"`, `did_config.hub_did: "did:key:..."`), then start `alexandria-client` alongside `fake-connector`:

```bash
./bin/fake-connector -listen 127.0.0.1:8282
./bin/alexandria-client -config config/client.yaml
```

Before its first sync, `/readyz` returns `503` and the Console **Status** page shows **`Onboarding`**.

### Sync immediately (`Sync now` or `POST /sync`)

<Tabs items={['Console UI', 'CLI / curl']}>
<Tab value="Console UI">

1. Switch to **Client → Status** (`g w` then `g s`).
2. Click **Sync now** (or simply press **`r`**).
3. The sidecar fetches the signed `VersionListing` and `1.0.0` package, verifies Ed25519 signatures and SHA-256 digests, and enters **`Active`** right away (since `1.0.0` is `initial`, `enforced_from = published_at`).

</Tab>
<Tab value="CLI / curl">

```bash
export ADMINAPI=http://127.0.0.1:9090

# Trigger an immediate synchronization instead of waiting for the poll interval
curl -s -X POST "$ADMINAPI/sync" | jq '{state, head}'

# Check readiness and status
curl -i "$ADMINAPI/readyz"
curl -s "$ADMINAPI/status" | jq '{state, head, sequence}'
```

</Tab>
</Tabs>

### Understand `Rules` and `verify.select: "/offer"`

Open **Client → Rules** (`g u`) and click **`contract-request`** (or `curl -s $ADMINAPI/rules/contract-request`):

- **`match`**: `POST /negotiations/{providerPid}/request` where `/@type` is `ContractRequestMessage` (or `dspace:ContractRequestMessage`).
- **`gates`**: `["dsp_message", "policy_intake"]`.
- **`Policy path` (`verify.select`)**: **`/offer`**. This tells `policy_intake` (ODRL JSON Schema + SHACL) to validate *only* the embedded `offer` sub-object while `dsp_message` validates the full protocol envelope!
- **`mode`**: `enforce`.

### Dry-run payloads safely with **Explain**

Before letting partner traffic hit the connector, test both valid and invalid `ContractRequestMessage` payloads using **Explain** (`POST /explain`):

<Tabs items={['Console UI', 'CLI / curl']}>
<Tab value="Console UI">

1. Open **Client → Explain** (`g x`).
2. Click the **`contract-request`** chip in the rule bar—Explain auto-fills a canonical **DSP 2025-1-err2** `ContractRequestMessage` (`action: "use"`, `dateTime lteq "2023-12-31T06:00Z"`).
3. Click **Explain** (or press `⌘↵`): verdict is **`forward`**.
4. Now change `"action"` inside `offer.permission[0]` to `"delete"` (which isn't in `mobility` `1.0.0`) and press `⌘↵`: verdict flips to **`reject`** with **`VERDICT_VIOLATION`** and exact gate findings!

</Tab>
<Tab value="CLI / curl">

```bash
# Valid DSP 2025-1 ContractRequestMessage (ok -> forward)
curl -s -X POST "$ADMINAPI/explain" -H 'Content-Type: application/json' -d '{
  "listener": "dsp-ingress",
  "method": "POST",
  "path": "/negotiations/urn:uuid:a343fcbf-99fc-4ce8-8e9b-148c97605aab/request",
  "body": {
    "@context": ["https://w3id.org/dspace/2025/1/context.jsonld"],
    "@type": "ContractRequestMessage",
    "providerPid": "urn:uuid:a343fcbf-99fc-4ce8-8e9b-148c97605aab",
    "consumerPid": "urn:uuid:32541fe6-c580-409e-85a8-8a9a32fbe833",
    "offer": {
      "@type": "Offer",
      "@id": "urn:uuid:d526561f-528e-4d5a-ae12-9a9dd9b7a815",
      "profile": "https://mobility.example/odrl/profile/mobility",
      "target": "urn:uuid:3dd1add8-4d2d-569e-d634-8394a8836a88",
      "permission": [{
        "action": "use",
        "constraint": [{"leftOperand": "dateTime", "operator": "lteq", "rightOperand": "2023-12-31T06:00Z"}]
      }]
    }
  }
}' | jq '{action, rule, findings}'
```

</Tab>
</Tabs>

### Send real traffic through `dsp-ingress` and capture an Agreement

With everything verified in Explain, send live requests through the proxy listener (`:9080`) using our custom GreenCity action **`https://mobility.example/ns/shareTelemetry`** vs an unknown action:

```bash
export INGRESS=http://127.0.0.1:9080

# 1. Valid GreenCity telemetry request -> 200 OK forwarded to fake-connector
curl -s -i -X POST "$INGRESS/negotiations/urn:uuid:a343fcbf-99fc-4ce8-8e9b-148c97605aab/request" \
  -H 'Content-Type: application/json' -d '{
    "@context": ["https://w3id.org/dspace/2025/1/context.jsonld"],
    "@type": "ContractRequestMessage",
    "providerPid": "urn:uuid:a343fcbf-99fc-4ce8-8e9b-148c97605aab",
    "consumerPid": "urn:uuid:32541fe6-c580-409e-85a8-8a9a32fbe833",
    "offer": {
      "@type": "Offer",
      "@id": "urn:uuid:d526561f-528e-4d5a-ae12-9a9dd9b7a815",
      "profile": "https://mobility.example/odrl/profile/mobility",
      "target": "urn:uuid:3dd1add8-4d2d-569e-d634-8394a8836a88",
      "permission": [{"action": "https://mobility.example/ns/shareTelemetry"}]
    }
  }'

# 2. Disallowed action -> 400 Bad Request (VERDICT_VIOLATION), never touches connector
curl -s -i -X POST "$INGRESS/negotiations/urn:uuid:a343fcbf-99fc-4ce8-8e9b-148c97605aab/request" \
  -H 'Content-Type: application/json' -d '{
    "@context": ["https://w3id.org/dspace/2025/1/context.jsonld"],
    "@type": "ContractRequestMessage",
    "providerPid": "urn:uuid:a343fcbf-99fc-4ce8-8e9b-148c97605aab",
    "consumerPid": "urn:uuid:32541fe6-c580-409e-85a8-8a9a32fbe833",
    "offer": {
      "@type": "Offer",
      "@id": "urn:uuid:d526561f-528e-4d5a-ae12-9a9dd9b7a815",
      "profile": "https://mobility.example/odrl/profile/mobility",
      "target": "urn:uuid:3dd1add8-4d2d-569e-d634-8394a8836a88",
      "permission": [{"action": "delete"}]
    }
  }'
```

When the connector later exchanges a `ContractAgreementMessage`, the client captures the agreement locally—pinned to version **`1.0.0`**—visible under **Client → Agreements** (`g g`) or `$ADMINAPI/agreements`. You can also watch live counters under **Client → Metrics** (`g m`).
