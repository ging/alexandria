# Alexandria Documentation

Welcome to the **Alexandria** documentation portal. Alexandria is an International Data Spaces (IDS) Vocabulary Hub providing decentralized identity, verifiable credentials, and semantic vocabulary services.

<Callout type="info">
Alexandria is built with Go, Hexagonal Architecture, and decoupled wallet ports, protected behind Zitadel OIDC authentication and Caddy TLS termination.
</Callout>
