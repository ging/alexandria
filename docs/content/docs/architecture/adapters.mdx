# Wallet Adapters

Alexandria provides two production-grade driven adapters implementing the `wallet.Wallet` port under `internal/ssi-auth/`.

---

## Feature Comparison

| Capability | Fafnir (`internal/ssi-auth/fafnir`) | Eclipse EDC IdentityHub (`internal/ssi-auth/identityhub`) |
|:---|:---:|:---:|
| **DID Methods** | `did:jwk`, `did:web` | `did:web` (multi-participant) |
| **Key Formats** | PEM (RSA, ECDSA, Ed25519) | JWK (`publicKeyJwk`), PEM (`publicKeyPem`), & Vault aliases |
| **Key Rotation & Revocation** | Stubbed (`ErrUnsupported`) | Full support (`RotateKey` with overlap duration, `RevokeKey`) |
| **DID Service Endpoints** | Stubbed (`ErrUnsupported`) | Full support (`AddServiceEndpoint`, `RemoveServiceEndpoint`) |
| **Credential Formats** | W3C VC (OID4VCI / OID4VP) | VC 1.0 (JWT) & VC 2.0 (JOSE), normalized via `normalize.go` |
| **Credential Issuance Protocol** | OID4VCI & OID4VP | Dataspace Credential Protocol (**DCP**) & direct storage |
| **Participant Contexts** | Single-tenant | Full multi-participant lifecycle (`CreateParticipant`, tokens, states) |
| **Default Port** | `7003` | `8181` (Identity API) / `8182` (DID / Credentials) |

---

## 1. Fafnir (`internal/ssi-auth/fafnir`)

**Fafnir** is a lightweight sovereign wallet focused on rapid local development and OID4VCI/OID4VP credential flows:
- Configured by default in `config/config.yaml` on port `7003`.
- Bootstrapped automatically via `task wallet:bootstrap` (`scripts/fafnir-bootstrap.sh`).
- Can store keys on a local Docker volume or inside **HashiCorp Vault** (`task vault:up`).

```yaml
wallet_config:
  wallet: Fafnir
  api:
    http:
      protocol: "http"
      url: "127.0.0.1"
      port: "7003"
```

---

## 2. Eclipse EDC IdentityHub (`internal/ssi-auth/identityhub`)

**Eclipse EDC IdentityHub** is the enterprise dataspace identity manager used across Eclipse Dataspace Components (EDC), Tractus-X, and Catena-X ecosystems:
- Communicates with the IdentityHub Management & Identity APIs (`edc_client.go`).
- Automatically base64url-encodes participant context IDs where required by the EDC REST specification.
- Normalizes heterogeneous credential representations (compact JWTs, JSON-LD credentials, and VC 2.0 JOSE envelopes) in `internal/ssi-auth/identityhub/normalize.go`.
- Comes with a dedicated configuration file `config/config-ih.yaml` and a comprehensive Postman collection under `postman/collections/Alexandria/Ssi-auth/IdentityHub/`.

### Running with IdentityHub

```bash
# 1. Start the IdentityHub container:
task identityhub:up

# 2. Run Alexandria using IdentityHub:
ALEXANDRIA_WALLET_CONFIG_WALLET=IdentityHub \
ALEXANDRIA_WALLET_CONFIG_API_HTTP_PORT=8181 \
task dev
```
