# DECISIONS

This document records the 14 PoC decisions defined in Part 2 of the specification (`DP-1`–`DP-14`) and the engineering decisions taken by the agent during implementation (Part 7).

## 2. Agent Decisions During Implementation

1. **Binary Naming in the Alexandria Monorepo (`cmd/alexandria-server`, `cmd/alexandria-client`, `cmd/alexandriac`):**
   - **Reason:** Per workspace convention established in this repository, the `vhub-server` and `vhub-client` binaries are named `alexandria-server` and `alexandria-client` under `cmd/alexandria-server` and `cmd/alexandria-client` (alongside `cmd/alexandriac` and `cmd/alexandria`), while preserving the exact F8 §8.2 internal package hierarchy (`internal/core`, `internal/server`, `internal/client`, `internal/clock`, `internal/testkit`).
2. **Bounded-Context `module.go` Wiring (`internal/server/module.go`, `internal/client/module.go`):**
   - **Reason:** Exposes `server.New(cfg, clock)` and `client.New(cfg, stateDir, clock, Opts)` as self-contained hexagonal modules so both standalone CLI binaries and in-process tests wire dependencies identically while enforcing F8 §8.6 construction guarantees (`Edge` has no `HubAPI` or `DIDResolver`; `Explain` has no `Upstream`, `AgreementRepo`, or `EventSink`; `Vocabularies` read path has no `UpstreamFetcher`).
3. **Direct `http.Transport.RoundTrip` in `proxy_dsp` (`REQ-SYS-003`, `REQ-CLI-014`):**
   - **Reason:** Standard `httputil.ReverseProxy` mutates `X-Forwarded-For` and `User-Agent` headers. Using `http.Transport.RoundTrip` directly in `internal/client/adapters/proxy_dsp` forwards the exact request/response bytes and headers untouched, adding only `VHub-Verdict` when specified by §4.8.
4. **Server `Date` Header Driven by `timex.Clock` (`REQ-CLI-025`, `DP-8`):**
   - **Reason:** `internal/server/adapters/httpx` writes the HTTP `Date` response header from the injected `timex.Clock` rather than `net/http`'s wall clock, making clock-skew estimation and `CLOCK_SKEW_EXCEEDED` deterministic under `file_clock`.
5. **Lab TLS Root Flag `-hub-ca` on `alexandria-client` (`DP-14`, `REQ-CLI-004`):**
   - **Reason:** `http_hub` requires `https://` for the hub URL; `-hub-ca` lets the E2E suite and `make demo` pass a transient self-signed 127.0.0.1 CA certificate without weakening default TLS verification.
6. **Offline JSON-LD 1.1 Processor (`internal/core/jsonld`) and Optional Profile DSL Compiler (`internal/dsl`, `internal/server/adapters/compiler_dsl`):**
   - **Reason:** `internal/core/jsonld` wraps `github.com/piprate/json-gold` with a strict offline `DocumentLoader` (never touching the network) used both by `evaluator_poc` to enforce `CONTEXT_NOT_IN_PACKAGE` (`REQ-CLI-010`) and by `http_v1_test` to verify JSON-LD expansion of `/v1` responses (`REQ-HUB-029`, DoD item 4). Additionally, `compiler_dsl` implements `app.ProfileCompiler` for `eunomia.profiles/v1` YAML profiles when `"compiler": "dsl"` is selected in `server.json`, while `"compiler": "poc"` (`compiler_poc`, `DP-6`) remains the default.
